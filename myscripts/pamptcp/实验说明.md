pamptcp 旨在实现一种能够感知优先级的 MPTCP scheduler。

运行命令：

```bash
./run-myscript.sh --mode opt \
  myscripts/pamptcp/pamptcp.cc \
  -- \
  --trafficProfileDir=myscripts/pamptcp/flow-priority-30/p3-sub-peak \
  --numAps=1 \
  --simTime=6 \
  --mptcpScheduler=default
```

运行完成后，会在实验目录生成结果文件，需要注意的是 delay_ms 和 jitter_ms 只会统计 steady 流（即 template_id 没有包含 peak），overall_delay_ms 才会统计
